# NEAT configuration for the Google Dino (T-Rex Runner) bot.
#
# NOTE: this file is intentionally ASCII-only. neat-python reads it using the
# system locale encoding, so non-ASCII characters can break parsing on Windows.
#
# Network inputs (11, all normalized to [0, 1]) - see dino.py:build_inputs():
#   1. speed_norm        current game speed / MAX_SPEED
#   2. tti_norm          time to impact = gap / speed (THE key feature)
#   3. gap_norm          distance to the nearest obstacle
#   4. obs_w_norm        width of the nearest obstacle
#   5. obs_h_norm        height of the nearest obstacle
#   6. obs_fly_norm      flight height of the obstacle above the ground
#   7. obs_is_ptero      1.0 if the nearest obstacle is a pterodactyl
#   8. dino_air_norm     dino height above the ground
#   9. dino_jumping      dino is currently jumping
#  10. dino_ducking      dino is currently ducking
#  11. duck_needed       1.0 if ducking would save the dino from this obstacle
#
# Network outputs (2, sigmoid, decision threshold 0.5):
#   1. jump
#   2. duck
#
# NOTE: the difficulty caps at MAX_SPEED, after which a correct policy can run
# forever. Reaching score 15000 takes roughly 13 minutes of real game time,
# so keep DINO_EPISODE_CAP high for the showcase run.
