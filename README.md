# Dino Bot

Умный бот для браузерной игры **Google Chrome Dino (T-Rex Runner)**.
Читает настоящее внутреннее состояние игры через движок сайта
(`window.Runner.instance_`) и играет реактивно, как опытный игрок:

* идеально перепрыгивает кактусы (учитывая текущую скорость игры);
* пригибается под птеродактилями, летящими на средней высоте;
* игнорирует птеродактилей, которые пролетают высоко над головой;
* перепрыгивает низколетящих птеродактилей;
* стабильно набирает тысячи очков и легко доходит до 20 000+.

## Требования

* Python 3.14+
* Playwright

Установка:

```bash
pip install playwright
playwright install chromium
```

## Запуск

```bash
python dino.py
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DINO_HEADLESS` | `0` | `1` — скрытый режим без окна (быстрее), `0` — показать окно |
| `DINO_TARGET_SCORE` | `20000` | До какого счёта играть в одной игре |
| `DINO_MAX_EPISODES` | `1000` | Сколько игр максимум сыграть |
| `DINO_GAME_SPEED` | `1.0` | Множитель скорости игры: `>1` — быстрее, `<1` — медленнее |
| `DINO_POLL_MS` | `12` | Пауза между шагами бота (миллисекунды) |
| `DINO_BROWSER` | `chromium` | Браузер: `chromium` / `chrome` / `firefox` |
| `DINO_JUMP_FACTOR` | `8` | Насколько заранее прыгать (см. ниже) |
| `DINO_JUMP_BASE` | `0` | Добавка к дистанции прыжка |
| `DINO_DUCK_FACTOR` | `10` | Насколько заранее приседать |
| `DINO_DUCK_BASE` | `8` | Добавка к дистанции приседа |

### Настройка скорости, эпизодов и цели

Скорость бега задаётся множителем `DINO_GAME_SPEED`. Он применяется к параметрам
движка (`SPEED`, `MAX_SPEED`, `ACCELERATION`) при каждом старте игры и является
идемпотентным — повторные применения не «накапливают» ускорение. Логика выбора
действий масштабируется текущей скоростью игры, поэтому бот корректно работает
при любом множителе.

Примеры:

```bash
# динозавр бежит в 2 раза быстрее (счёт растёт намного быстрее)
set DINO_GAME_SPEED=2      # Windows (cmd)
export DINO_GAME_SPEED=2   # Linux/macOS

# медленнее и надёжнее, цель 50 000 очков, 5 игр
set DINO_GAME_SPEED=0.7
set DINO_TARGET_SCORE=50000
set DINO_MAX_EPISODES=5
```

## Как это работает

Бот в цикле опрашивает состояние игры (`status`, `score`, `speed`, позиции
динозавра и ближайших препятствий) и выбирает одно из действий: `jump`,
`duck` или `none`. Момент прыжка/приседа вычисляется по дистанции до
препятствия, масштабированной текущей скоростью игры.

### Важный нюанс физики прыжка

При 60 FPS (оконный режим с vsync) прыжок с фиксированной начальной
скоростью длится ~28 кадров, поэтому динозавр достигает пика и начинает
спускаться ещё до конца полёта. Если прыгнуть слишком рано
(`gap ≈ speed * 14`), динозавр в момент прохождения широкого кактуса
(`CACTUS_LARGE`, ширина 75 px) уже опускается и задевает его — бот
погибает на ~50–140 очках.

Поэтому `JUMP_FACTOR` подобран так, чтобы пик прыжка совпадал с
прохождением препятствия:

```
gap = speed * JUMP_FACTOR + JUMP_BASE   # JUMP_FACTOR ≈ 8
```

В headless-режиме частота кадров другая, и проблема не проявлялась, что
затрудняло диагностику.
