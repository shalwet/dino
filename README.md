# Dino Bot — обучение нейросети через NEAT

Проект обучает нейросеть игре **Google Chrome Dino (T-Rex Runner)** с помощью
нейроэволюции **NEAT**. Обучение идёт **асинхронно сразу в 15 браузерах
Chromium**: каждая особь популяции играет в своём изолированном окне, читает
настоящее внутреннее состояние игры (`window.Runner.instance_`) и автономно
принимает решения.

Запуск делает всё сам: сначала **обучение** (по умолчанию в скрытых окнах,
чтобы было быстрее), а в конце **сам открывает видимое окно** и запускает
лучшего найденного бота, чтобы можно было наблюдать за бегущим динозавриком.
**Отдельный скрипт для просмотра не нужен.**

## Как это работает

```
            asyncio.event_loop
                    │
   ┌────────────────┼────────────────┐
   ▼                ▼                ▼        ... ×15 браузеров
┌──────────┐   ┌──────────┐   ┌──────────┐
│ Chromium │   │ Chromium │   │ Chromium │
│  genome1 │   │  genome2 │   │  genomeN │
└────┬─────┘   └────┬─────┘   └────┬─────┘
     │ состояние игры (JS_READ)    │
     ▼                              ▼
┌─────────────────────────────────────────┐
│ NEAT: fitness → отбор → мутации → новое │
│ поколение                                │
└─────────────────────────────────────────┘
```

* Каждая особь — это **нейросеть прямого распространения** (feed-forward),
  созданная из генома NEAT.
* Входы сети (11 нормализованных признаков): скорость игры,
  **время до столкновения** (`gap / speed` — ключевой признак), дистанция до
  ближайшего препятствия, его ширина/высота/высота полёта, признак
  «птеродактиль», высота динозавра над землёй, флаги прыжка и приседа и
  подсказка «присед поможет».
* Выходы сети (2): **jump** и **duck**. Решение принимается по порогу 0.5.
* **Fitness** особи = её **счёт (очки)**. Дополнительный бонус за время нужен
  лишь чтобы различать особей с нулевым счётом на старте.

> **Путь к 15000**: сложность игры упирается в `MAX_SPEED` примерно через
> 2 минуты, после чего верная политика может бежать бесконечно. Счёт растёт
> в среднем на 12–19 очков в секунду, поэтому **15000 очков — это примерно
> 13 минут реального времени игры**. Для показа это нормально, но во время
> обучения ставьте разумный лимит на игру (`DINO_EPISODE_CAP`).

Подробное описание входов/выходов — в [`neat_config.txt`](dino/neat_config.txt).

## Требования

* Python 3.14+
* Playwright
* neat-python

Установка:

```bash
pip install playwright neat-python
playwright install chromium
```

## Запуск

```bash
python dino.py
```

Что произойдёт:

1. Поднимутся **15 скрытых окон** Chromium и пойдёт обучение. Прогресс
   печатается по каждому поколению (лучший/средний счёт, время).
2. Лучший геном сохраняется в `dino_best.pickle`.
3. По завершении (или при достижении `DINO_TARGET_SCORE`) откроется
   **видимое окно** Chromium и лучший бот начнёт играть по кругу.

Остановить показ можно, закрыв окно или нажав `Ctrl+C`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DINO_WORKERS` | `15` | Число параллельных браузеров (= размер популяции NEAT) |
| `DINO_TRAIN` | `1` | `1` — обучаться; `0` — только показать сохранённый геном |
| `DINO_TRAIN_HEADLESS` | `1` | `1` — скрытые окна при обучении (быстрее) |
| `DINO_SHOW` | `1` | `1` — в конце открыть видимое окно с лучшим ботом |
| `DINO_SHOW_EPISODES` | `0` | Сколько игр показать (`0` — бесконечно) |
| `DINO_MAX_GENERATIONS` | `100` | Сколько поколений учить (`0` — без ограничения) |
| `DINO_TARGET_SCORE` | `15000` | При достижении такого счёта обучение остановится |
| `DINO_GAME_SPEED` | `1.0` | Множитель скорости игры: `>1` — быстрее, `<1` — медленнее |
| `DINO_POLL_MS` | `10` | Пауза между шагами бота (миллисекунды) |
| `DINO_EPISODE_CAP` | `1500` | Максимальная длительность одной игры (секунды) |
| `DINO_SAVE_PREFIX` | `dino_best` | Префикс файлов сохранения лучшего генома |

Примеры:

```bash
# Обучение, затем показ (по умолчанию)
python dino.py

# Только показать уже обученного бота (без обучения)
set DINO_TRAIN=0
python dino.py

# 15 видимых окон при обучении, 30 поколений, игра в 1.5 раза быстрее
set DINO_TRAIN_HEADLESS=0
set DINO_MAX_GENERATIONS=30
set DINO_GAME_SPEED=1.5
python dino.py
```

## Детали движка (для тех, кто настраивает признаки)

Из [`game_reference/dino_index.js`](game_reference/dino_index.js):

* Canvas: `600 × 150`. Верх динозавра `groundYPos = 93`, **уровень земли
  (низ динозавра и препятствий) `y = 140`**.
* Конфиг `Runner.config`: `SPEED 6`, `MAX_SPEED 13`, `ACCELERATION 0.001`,
  `GRAVITY 0.6`, `SPEED_DROP_COEFFICIENT 3`.
* Динозавр `Trex.config`: `WIDTH 44`, `HEIGHT 47`, `HEIGHT_DUCK 25`,
  скорость прыжка = `-(10 + currentSpeed / 10)`.
* Препятствия:
  * `CACTUS_SMALL` — `17 × 35`, `yPos 105`;
  * `CACTUS_LARGE` — `25 × 50`, `yPos 90`;
  * `PTERODACTYL` — `46 × 40`, `yPos ∈ {100, 75, 50}` (низко/средне/высоко),
    появляется при `speed ≥ 8.5`, `speedOffset ±0.8`.
* Счёт = `distanceRan × COEFFICIENT` (`COEFFICIENT = 0.025`).
* Ввод: события `keydown`/`keyup` на `document`; `Space`/`ArrowUp` — прыжок,
  `ArrowDown` — присед; перезапуск — `Runner.instance_.restart()`.
